# kintsugi-brickit

Brick'It — a breakout/arkanoid-like game built on Kintsugi, developed incrementally.

```bash
./gradlew :brickit:desktop:run                      # Desktop (JVM)
./gradlew :brickit:web:wasmJsBrowserDevelopmentRun  # Web (WASM)
./gradlew :brickit:android:installDebug             # Android (needs the Android SDK and a device)
```
